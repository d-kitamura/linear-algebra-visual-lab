## 1. 学習目標と対象範囲

学生が、非零ベクトルの像がその定数倍となる意味、固有値と伸縮・反転・零への写像の関係、同じ固有値に属するベクトル全体が部分空間になることを理解できるようにする。固有方程式と固有空間を数値・数式・図で結ぶ。対角化の可否を判定する教材にはまだ進まない。

| 項目 | 採用方針（D-102） |
|---|---|
| Lab | 第五Lab `eigenspace`。メニュー「固有値・固有空間Lab」、ページ見出し「固有値と固有空間」 |

### 表現行列Labとの重要な違い

第四Labでは定義域基底Bと終域基底Cが異なってもよいが、その行列の固有値が線形変換自体の固有値を表すとは限らない。例えば恒等写像でも、BとCが異なれば表現行列はEとは限らない。

本Labでは**同じ空間、同じ順序付き基底を入出力に用いる**。同じ変換を別の基底で表した行列の比較は、将来、両側の基底を同時に変更する責務として追加できる。第四Labの正方行列Aをそのまま送る連携は実装しない。

## 2. 記号と数学表示

- 観察する入力は `\bm u`、像は `T(\bm u)`。多項式では `\bm u=f(x)` とし、基準係数を `b_0,b_1,b_2` で示す。
- 主式は `T(\bm u)=\lambda\bm u`、ただし `\bm u\ne\bm0`。数ベクトルでは `\bm A\bm u=\lambda\bm u`、多項式では係数ベクトルに対する式と区別する。
- 固有空間は `W(\lambda;T)=\{\bm u\in U\mid T(\bm u)=\lambda\bm u\}`。実固有値λに対し `W(\lambda;T)=Ker(T−\lambda I_U)`。行列側の核との対応は基準座標を介して示す。
- 固有多項式は `g(\lambda)=det(\bm A−\lambda\bm E)`、固有方程式は `g(\lambda)=0`。奇数次で`det(λE−A)`とは符号が反対なので、表示とテストを固定する。
- λ=0も固有値になり得る。像が零の場合は「平行」という説明だけにせず「零へ写る」と示す。入力零は任意のλで等式を満たすが、固有ベクトルではない。
- 固有値の重複度と固有空間の次元は別の量。例えば同じ重根2でも `2E` と `[[2,1],[0,2]]` の固有空間の次元は異なる。12.1で表示語を「固有値の重複度」とし、固有方程式の根として重なる回数と説明する（D-103）。
- 基底は順序付き組、成分は列ベクトル、横書きは左肩転置記号。行列・ベクトルは既存数式部品を再利用し、添え字の数字は立体レギュラーとする。

画面には検証済み数値を既存の有効数字規則で表示するが、本Labの解析カードの数式はD-106により「=」へ統一する。内部計算・URLの値を表示桁数へ丸めない。固有空間の基底の一例は計算上の便宜であり、唯一の基底や唯一の固有ベクトルとは説明しない。

## 3. 画面と操作

### 単一グラフで入力と像を比較

線形変換なので、DomainとCodomainの別々の図ではなく、**同じ図・同じ表示範囲**に入力uと像T(u)を重ねる。通常入力は非零の既定値を持ち、クリック作成のモードは不要。入力の矢先だけをドラッグ・成分入力で編集でき、像は導出値として直接編集しない。

- 入力は青、像は赤系の不透明矢印を第一案とし、色だけでなくu／T(u)の数式ラベルでも区別する。
- 同方向・同位置に重なるときも像を読み取れるよう、線幅・矢先形状とラベル位置を調整する。λ=1の完全一致では一つの矢印に両ラベル、像が零なら原点の印で示す。原点から人為的にずらして描かない。
- 固有空間の表示は初期オフ。オンにすると全固有値の確認済み固有空間を同時に灰色で表示する（D-106）。異なる直線を合成した平面として描かない。直線・板・全空間は既存のspan描画を再利用し、平面に追加の格子を置かない。3Dの全空間は既存の箱と半透明表示を使う。
- 行列が変わると固有値・空間・像を更新。入力のドラッグだけなら行列の固有値分解は再計算せず、像と入力判定だけをリアルタイム更新する。
- 3D操作は既存と同じく、背景ドラッグで回転、矢先ドラッグで画面平行面内を移動。ホイール・ピンチ・全体表示を共用する。
- 自動範囲には入力と像を含める。固有空間は無限に広がるので、空間描画自体を自動範囲計算へ入れない。ドラッグ中に自動範囲が動いて操作を妨げないよう既存方式を引き継ぐ。

### 吸着

表示中で数値検証済みの全固有空間のうち最も近い空間へ、入力のドラッグ時だけ吸着する。数学判定とUI吸着の閾値は分離し、2Dは表示幅2%、3Dは正投影表示幅3%を既存共通値として使用する。1Dは既存の数直線の原点吸着に合わせる。ヒステリシスは初期実装では加えない。

原点を最優先とし、零になった入力には「固有ベクトルではありません」と表示する。全空間への吸着は移動量0なので何もしない。数値的に不確かな空間へは吸着させず、入力を勝手に数学的正解へ変更しない。数値入力には吸着を適用しない。

### カード・レスポンシブ

PCはグラフ＋行列／入力の編集カード、解析は「固有値」「固有空間」「入力と像」「固有方程式」のタブ形式とする。表示する解析カードは常に1つ。狭幅ではグラフ・編集・解析の順へ並べ、タブと既存ヘッダーの方式を共用する。詳細配置は2D縦断版で利用者が確認する。

全固有空間の表示オン／オフは解析タブを切り替えても利用できるようにする。固有値のプルダウンは置かない。常設の長い補足、授業例一覧、独立読み上げ要約パネル、0D説明パネルは追加しない（D-100）。数式・入力の読み上げラベル、キーボード操作、WebGL代替の数値解析は維持する。

## 4. 数値計算の契約と技術検証

既存の行列作用・核・rank・生成する空間・表示部品を再利用できるが、**近似固有値をA−λEへ代入して既存のrank判定を呼ぶだけでは不十分**。λの誤差で本来の核が消えたり、近接根を重根と誤判定したりするため、固有値と固有空間の精度契約を数学API側に設ける。

### API境界（12.1の名称・契約はAPI契約書参照）

1. 変換の解析: 正方行列と次元から固有多項式、実固有値候補、重複度、固有空間基底、次元、残差と判定状態を返す。図やReactには依存しない。
2. 入力の解析: 変換解析結果と入力から、零入力・全固有空間への所属・等式の残差を返す。任意の単一空間検査は数学APIだけに残し、UIは一致根一覧を使う。
3. 可視化への変換: 検証済みの空間基底から共通の直線・平面・全空間表示と吸着候補を作る。固有空間基底を正規化しても、入力ベクトルや保存された行列は変えない。

解析全体および各根の結果を「数値基準内で確認」「実固有値なし」「判定保留／数値計算失敗」に分ける。不確かな根の重複度や固有空間次元はnullにできる契約とし、0や1を仮置きしない。確かな部分結果を示す場合も一覧が完全でないことを表示する。

### 計算法を確定する前の検証

- 0Dは空行列の固有多項式1、固有値なし、非零入力なし。1Dは行列成分そのものが固有値。零行列も通常の明確なケースとして扱う。
- 2D・3Dの実根探索・重複度判定・空間抽出の方式は12.2で技術検証する。一般の非対称行列にも対応する。対称行列専用の解法や1根だけの反復法で済ませない。
- 入力をスケーリングし、根の多項式残差、空間基底の独立性、`Aq≈λq`の残差、根の個数・重複度の整合を確認する。残差が小さいだけで重根の正確な分類や全根の発見が保証されたとは説明しない。
- 固有値の丸め表示が同じだからといって統合しない。小さい虚部を無条件に0にしない。微小な実固有値を無条件に0にしない。根の分離やrankが数値誤差に対して不安定な場合は判定を保留する。
- 固有空間抽出の許容誤差は行列スケール・λの誤差を考慮した専用契約とする。既存D-009や他Labのrank閾値を一括変更しない。具体的な許容値は12.2の境界テストの結果を根拠に決定記録へ残す。
- 入力上限は既存の有限値・絶対値100万以下を出発点とする。導出値は上限で切り詰めず、非有限・精度不足を安全に扱う。収束回数には上限を設け、UIを無期限に停止させない。
- 12.2では追加依存なしの方式を実装した（D-104承認済み）。今後依存が必要なら実装・保守負担、ライセンス、ブラウザビルド、容量を比較して承認を得る。数学契約を満たせない場合は範囲を黙って縮小せず、その時点で相談する。

基底ベクトルの符号・順序の揺れによる図のちらつきを抑えるため、数値的に安定な範囲で正規化規則を固定する。異なる実装の基底配列の文字列一致を正しさの条件にせず、生成する空間と残差で検証する。

## 5. 多項式の線形変換

同じ多項式空間の自己写像を用いる。係数に対してAを作用させ、その結果が多項式の像に対応することを明示する。

- 微分 `T(f)=f'` は、例えば高々2次から**同じ高々2次空間**への変換とする。像の2次係数は0。第四Labの3→2微分例とは終域が異なる。
- `T(f)=x f'` は各単項式の次数が固有値になる例。高々2次では0,1,2、固有空間はそれぞれ定数・xの倍数・x²の倍数。
- `T(f)(x)=f(x+1)` は同じ空間を保つ例。高々2次では固有値1が重複し、固有空間は定数多項式の直線になる。
- `f→xf` は一般に次数上限を超えるため、そのままの形では今回の自己写像例に含めない。打切りを暗黙に加えて別の写像にしない。

任意基底の座標エクスプローラを再実装しない。まず基準係数による自己写像と固有多項式／固有関数の対応を扱う。教科書にない用語を増やさず、画面は「固有ベクトルである多項式」と説明する。

## 6. 状態・共有・Reset

- 共有候補は独立した `(lab,v)=(eigenspace,1)`。現在の1場面の種別・次元・行列・入力・固有空間表示設定・3Dカメラを保存する。既存4Labの形式は変更しない。
- 根や固有空間基底、rank、残差、固有多項式の係数は導出値として保存しない。D-106で単一根選択を廃止し、共有にも選択序数を保存しない。
- 行列編集時は全根と固有空間を再解析する。初期表示オフ、全空間同時表示、最短距離への吸着をD-106とAPI契約書で定める。
- 現在場面の共有時InitialStateをReset基準とし、他の種別・次元の状態をリセットしない。再エクスポートで初期値を書き換えない。
- 入力下書き・ドラッグ途中は共有しない。数学解析の保留は不正入力と別であり、有効な行列なら保留例も共有可能とする。共有後も解析を再計算して保留表示を維持する。
- 手動表示範囲・解析タブは保存しない。復元は入力と像を含む全体表示、3Dだけ共有視点を反映。URL・QR・PNG・テキスト・コピー・2048文字上限と厳密なURL検証は既存方式を共用する。
- 0Dは固定状態を最小化し、存在しない入力・カメラ・根選択を保存しない。複素数や多項式文字列をJSONへ持ち込まない。

## 7. 代表例と検証観点

下記は実装時に独立期待値と共有URL付きMarkdownへする候補。いまはアプリに例ボタンを追加せず、URLも未生成。

| 例 | 行列／変換 | 期待する観察 |
|---|---|---|
| 1Dの反転伸縮 | [-2] | λ=−2、非零入力すべて固有ベクトル |
| 2Dの異なる実固有値 | diag(2,−1) | 2本の固有直線、伸縮と反転 |
| 軸に沿わない固有空間 | [[2,1],[1,2]] | λ=3と1、直線y=xとy=−x |
| 固有値0 | diag(1,0) | 核がW(0;T)、像が零でも入力は固有ベクトルになれる |
| 全空間が固有空間 | 2E | λ=2、重複度n・固有空間次元n |
| 同じ重根でも直線のみ | [[2,1],[0,2]] | λ=2、重複度2・固有空間次元1 |
| 実固有値なし | [[0,−1],[1,0]] | 90度回転、g(λ)=λ²+1、非零固有ベクトルなし |
| 3Dの平面と直線 | diag(2,2,−1) | W(2;T)は平面、W(−1;T)は直線 |
| 3Dの実根1個 | [[0,−1,0],[1,0,0],[0,0,2]] | 実固有値2のみ、他の2根は実数でない |
| 零変換と零入力 | O、別例でu=0 | n>0ならλ=0・全空間、ただし入力零は固有ベクトルでない |
| 0D | 空行列 | g(λ)=1、固有値・固有ベクトルなし |
| 多項式の微分 | R[x]_2上のD | λ=0、重複度3、定数の1次元固有空間 |
| 多項式の次数 | R[x]_2上のxD | λ=0,1,2、単項式ごとの固有空間 |
| 多項式の平行移動 | f(x+1) | λ=1、重複度3、定数の1次元固有空間 |

数値境界テストは教材例と別に、近接する実根、非実根の実軸への接近、微小な非零根、大きい／小さいスケール、重根の摂動を含める。期待値は既存の解析結果から自己生成せず、既知の行列構造から独立に用意する。合否は数字の見た目の一致だけでなく、保留すべきケースで誤断定しないことも含む。
