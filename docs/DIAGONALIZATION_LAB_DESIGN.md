## 1. 目的とLabの位置づけ

第6の「対角化Lab」を追加し、大見出しは「行列の対角化」とする。第五Labは固有値・固有空間の観察に残す。第六Labは固有ベクトルを基底にすることと、対角化可能性の理解に集中する。

利用者指示（2026-09-14）により、ケイリー・ハミルトンの定理・次数落とし・そのモードや関連API／テストは本Labからすべて除外する。べきの計算機能も今回は設けず、後続フェーズへの自動移管も行わない。

学習目標は次の2点。

1. 固有空間から一次独立な固有ベクトルをn本取れることと、実数上で対角化できることを結び付ける。重複する固有値があっても対角化できる例と、できない例を比較する。
2. 対角化を「別の写像に変更する操作」ではなく「同じ線形変換を固有ベクトルの基底で表す操作」として理解する。

対象は実数上の自己写像。数ベクトル0〜3D・多項式1〜3Dの7場面とする。多項式空間は\(\mathbb R[x]_{n-1}\)、基準基底は\((1,x,\ldots,x^{n-1})\)。異なる種類や次元間の写像は扱わない。Jordan標準形、最小多項式、複素対角化、負のべき、行列指数関数、内積・正規直交対角化は範囲外。

## 2. 記号と対応式（D-115承認済み、表記規則へ追記済み）

入出力には同じ基準基底\(\mathcal E\)を使い、その行列を\(\bm A\)、入力を\(\bm u\)、像を\(T(\bm u)\)とする。第五Labの記号を引き継ぎ、第四Labの\(\bm M\)との役割差を説明する。第四Labの入出力基底が異なる一般の表現行列を、そのまま対角化対象として自動転送しない。

固有ベクトルの順序付き基底と、それを基準座標に並べた行列は

\[
\mathcal B=(\bm p_1,\ldots,\bm p_n),\quad
\bm P=\bigl[[\bm p_1]_{\mathcal E}\ \cdots\ [\bm p_n]_{\mathcal E}\bigr],\quad
\bm D=\operatorname{diag}(\lambda_1,\ldots,\lambda_n).
\]

数ベクトルの標準基底では\(\bm P=[\bm p_1\ \cdots\ \bm p_n]\)と書ける。多項式の場合は\(\bm p_i=f_i(x)\)と、その係数列を区別する。行列を丸括弧の組と混同しない。

\[
\bm A\bm P=\bm P\bm D,\qquad
\bm P^{-1}\bm A\bm P=\bm D,\qquad
\bm A=\bm P\bm D\bm P^{-1}.
\]

\(\bm P\)の向きは「固有ベクトル基底\(\mathcal B\)の座標 → 基準基底\(\mathcal E\)の座標」。既存規則では\(\bm P_{\mathcal E\leftarrow\mathcal B}\)に当たる。逆向きと取り違えない。

\[
\bm c=[\bm u]_{\mathcal B},\quad
[\bm u]_{\mathcal E}=\bm P\bm c,\quad
[T(\bm u)]_{\mathcal E}=\bm A\bm P\bm c=\bm P\bm D\bm c,\quad
\bm u=(\bm p_1,\ldots,\bm p_n)\bm c.
\]

多項式の基準係数には\(b_0,b_1,b_2\)、選択基底の座標には\(c_1,c_2,c_3\)を使う。文字のみ太字斜体、添え字の数字は立体レギュラー。通常は列表示、横書きが必要なら左上転置記号を付ける。UIの数式は既存フォントを共用する。

等号は第五Lab同様、通常の教材等式では「=」を使う。ただし丸め値は判定に使わず、数値的に確かめられない結果は式を成立済みとして出さない。残差は必要時の詳細表示に置き、一般の行列や実数に対する厳密計算を保証しない。

## 3. 対角化の判定と基底

実数上で対角化可能であることは、実固有値に対応する固有空間の次元の総和がnであることと同値。ただしAPIの未確認空間を0次元として足さない。

| 結果 | 条件と画面の扱い |
|---|---|
| 対角化できる | 必要な実根・空間が確認でき、n本の基底から作ったPの独立性・条件・AP=PDの残差を検証できる。Dと座標の図を提示 |
| 実数上では対角化できない | 非実根の存在が確定している、または完全に確認された実固有空間の次元総和がn未満。根拠を併記し、Pの逆行列やDを作らない |
| 数値的に判定を保留 | 不完全な根集合、nullの空間、不安定な方向、Pの条件不良など。数学的な不可と区別し、原因と編集可能な元の行列を残す |
| 数値計算失敗 | 演算上限・表現不能等。失敗を零行列・零次元・対角化不可へ置換しない |

非実根の存在など確定した否定根拠があれば、他の未確定値があっても実数上の不可を説明できる。逆に`status=ready`だけで自動的に対角化可能とはしない。数学的な判定、Pの構成の可否、入力座標の計算の成功を別々に保持する。座標だけのunderflowで行列の対角化可能性を否定しない。

基底は確認済みの固有空間から自動構成した**一例**を初期表示する。実固有値の昇順とAPIの空間内順を基準に、各列の最大絶対成分を正の1へ揃える（同率は成分順）。見た目を整えた後も残差を検算する。分数・根号の推測や整数化はしない。別々の固有空間に属するベクトルをまとめて直交化してはならない。

初版では列の順序交換を提供し、PとDの対応を同時に変える。自由な基底成分編集・スカラー倍編集・重根内の混合編集は後続候補とする。順序交換でu自体は変わらず座標cが変わる。Aの編集時は順序を既定へ戻し、古い根への対応を残さない。Pが得られない場合の「部分的な固有ベクトルの組」は基底とは呼ばない。

## 4. 画面・操作

- 共通Labメニュー、大見出しを最上部、共有／Resetを同じ高さの右側、種別・次元選択をその下へ配置。既存5Labの配置・Math部品・数値入力を共用する。
- 左に「基準基底での表示」、右に「固有ベクトル基底での座標」を表示する。左右はDomain／Codomainではなく、同じ入力と同じ像の**異なる座標表示**である。右はcとDcであり、斜交基底を物理空間の直交軸と誤解させない。
- PCは左右2図、狭幅は上下に近接配置。その下に全幅の詳細タブを置く。行列・入力の編集は常設のコンパクトな領域、解説は「対角化の条件」「固有ベクトルの基底」「座標と作用」の3タブから1枚だけ表示する。カードを縦に積み上げない。
- 入力uは左図の矢先ドラッグと数値入力で編集し、右図cとDcをリアルタイム更新。右図は初版では読取専用の矢印とし、パン・ズーム・3D視点は操作可能。Pの列や像は矢先編集しない。左の空間表示と吸着は第五Labの規則を共用（初期非表示、原点優先）。
- 対角化不可／保留の場合も左図・成分編集を維持する。右の領域には理由を示し、前のDや偽の零座標は描かない。幅・高さは過剰に確保しない。
- 導出した座標が大きくなっても入力成分の上限100万で切り捨てない。描画限界を超えた場合は数値・式を残して幾何表示のみ保留し、理由を示す。具体的な描画上限は13.1で既存Viewportの範囲と照合する。

## 5. 0D・1D・3D・多項式

0Dでは空の順序付き基底と0×0のP・Dを持つ形式的な対角化を扱い、「固有値はないが空の基底で表せる」とする。図は一点、存在しない成分や根を追加しない。空の基底・空行列の説明は既存タブ内に短く置く。0D共有は最小形式とし、存在しない行列成分やカメラを持たせない。

1Dは実スカラー倍なので常に対角化可能（零変換を含む）。3Dは既存の右手系・黒い軸・画面平行面ドラッグ・原点優先吸着を共用する。左右のカメラは独立し、右の軸はc_1,c_2,c_3とする。

多項式の図は関数グラフではない。左はb_0,b_1,b_2の係数空間、右は固有ベクトルとなる多項式の基底に関するc_1,c_2,c_3の座標空間。u=f(x)、T(u)、固有基底の多項式とそれぞれの係数列を対応付ける。微分と平行移動は高々1次以上では一般に対角化不可の教材、xf′は標準単項式基底で対角化済みの教材とする。高々0次の例外を別に検証する。

## 6. 状態・共有・Reset

第六Labは他Labと独立したWorkspaceを持つ。7場面それぞれに行列・入力・基底列の順序・空間表示・左右の表示範囲／カメラを保持する。詳細タブは一時UI状態とする。

最初は数ベクトル2D、Aは第1行(4,1)・第2行(0,2)、uの列成分は(1,2)、空間表示オフ。その他の初期行列と入力は第五Labの同じ種類・次元の例を引き継ぎ、状態オブジェクトは共有しない。両図の初期表示は全体表示、初期解析タブは「対角化の条件」とする。

Resetは現在の種類・次元の場面を起動時状態へ戻し、他場面には触れない。共有から起動した場面は共有時、他場面は既定値へ戻る。再エクスポートは初期状態を更新しない。

共有は独立した`(lab,v)=(diagonalization,1)`を採用する。現在の1場面の種類・次元・A・u・列順序・空間表示・両3Dカメラを保存。自動導出するP・D・根・解析結果・詳細タブ・手動1D/2D範囲・下書き・ドラッグ途中は保存しない。

列順は固定の自動構成順に対する置換で表し、全列が得られないときはnull。復元時に長さ・重複・解析との整合を検証し、無言で別の基底順へ替えない。将来のソルバー変更でこの順序を変える場合の版更新は13.6で明文化する。授業用の基底の厳密な見た目の永続保証は、正式リリースの互換契約で定める。

既存のURL長2048文字、QR／PNG／テキスト保存、現在の公開path、異常値の拒否、共有中のsnapshotを共用する。例外なく常に共有できるとは約束せず、長すぎる場合は既存の理由表示を使う。5Labの形式・初期化を変更しない。

## 7. 数学API・再利用の作業境界

13.1で定める公開契約は、行列の対角化判定・P/D構成と、入力座標の解析を分離する。React・カメラ・URLを数学APIへ渡さない。入力ドラッグでは行列の解析・根探索を再実行しない。A・列順・uのどれが変わったかで再計算範囲を分ける。

再利用の対象は`analyzeEigenMap`、表現行列／基底変換の解法と検算、共通0〜3D描画、Math部品、共有ダイアログ。新しい入力上限や独立性の閾値を場当たり的に作らず、既存APIの失敗理由を新Labの「不可」と混同しない。固有値APIが返す空間基底だけから、悪条件Pの安全な逆行列を保証しない。

現時点では新規数値ライブラリを追加しない案。既存部品の安全な再利用ができない場合や数値契約の変更が必要な場合は、その作業単位で判断を求める。計画承認を閾値・アルゴリズムの一括承認として扱わない。

## 8. 代表例と独立期待値

通常教材と数値境界を別枠にする。既存70例は変更せず、新LabのURLは実装後のMarkdownへ追加する。

| 例 | 主な期待値・観察 |
|---|---|
| 初期A=\(\begin{bmatrix}4&1\\0&2\end{bmatrix}\)、u=\({}^t[1,2]\) | λ=2,4。P=\(\begin{bmatrix}-0.5&1\\1&0\end{bmatrix}\)、D=diag(2,4)、c=\({}^t[2,2]\)。列の順序変更でも同じu・Auを表す |
| \(\begin{bmatrix}2&1\\1&2\end{bmatrix}\) | 固有値1,3、斜めの固有基底。固有値1は初期例以外の比較用として残す |
| 2E、diag(2,2,−1) | 重根があっても各固有空間から十分な本数が取れる。基底の一意性と誤解しない |
| \(\begin{bmatrix}2&1\\0&2\end{bmatrix}\) | 重複度2・固有空間次元1、対角化不可。不足する固有ベクトルを勝手に補わない |
| \(\begin{bmatrix}0&-1\\1&0\end{bmatrix}\) | 実数上では対角化不可。複素数上の対角化を表示しない |
| 零変換・零入力・0D | n>0の零変換は対角化可能。零入力で行列の判定は変わらない。0Dに偽の固有値0を追加しない |
| 1Dの負・零スカラー | いずれも1本の基底で対角化可能。零の固有値も認める |
| 高々2次の微分 | 固有値0、固有空間は定数のみ、対角化不可 |
| 高々2次のxf′ | D=diag(0,1,2)。関数の係数と固有基底座標を対応付ける |
| 高々2次のf(x+1) | 固有値1・固有空間次元1、対角化不可 |

全例でAP=PDだけでなく、独立に作った数値期待値、列順交換、共有復元・Resetを検証する。数値境界では近接根・ほぼ重なる固有方向・非常に小さい非零値・underflow・不正入力を扱う。共通ソルバー自身の出力から期待値を生成して正しさの根拠にしない。
