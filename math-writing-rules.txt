以下は数学記号をTeXのスタイルで表記している．但し，\bm{}は太字斜体を表す（\usepackage{bm}が必要）．

文字のフォント：スカラーはレギュラー斜体の小文字を使う（a, c1等），ベクトルはボールド斜体の小文字を使う（\bm{a}, \bm{c}_1等，ゼロベクトルは\bm{0}），行列はボールド斜体の大文字を使う（\bm{A}, \bm{C}_1等，ゼロ行列は\bm{O}），実数集合には白抜き文字を使う．授業でよく出てくる実数上のベクトル集合は，n次元実数ベクトル集合\mathbb{R}^n，n行m列の実数行列集合\mathbb{R}^{n \times m}，xを変数とする高々n次の実数係数多項式集合\mathbb{R}[x]_nである．なので，\bm{a} \in \mathbb{R}^n（数ベクトルの例）や\bm{A} \in \mathbb{R}^{2 \times 3}（行列の例）やf(x) \in \mathbb{R}[x]_2（高々2次多項式の例）のように定義する．但し，多項式はベクトルであるので，\bm{v} = f(x) = x^2 + 3x + 1のように太字斜体小文字でも関数f(x)でも表記する（文脈に合わせて使い分けたり，\bm{w} = g(x) = のようにどちらも書いたりする）．その他の集合はVやWやXなど，レギュラーフォントの大文字を使う．特殊な例として，空集合は\emptysetを使う．
数ベクトルの原則：数ベクトルは特に断りがない限り列ベクトル（縦ベクトル）とする．従って\mathbb{R}^nは，n個の要素を持つ列ベクトルの集合となる．
ベクトルや行列や集合の中身の呼び方：ベクトルや行列に対しては，「成分」と呼ぶ時と「要素」と呼ぶ時が授業を通して混在する．どちらも慣れてほしいと思っている．集合の中身は原則「元」と呼び，「要素」と呼ぶことも時々ある．
ベクトルや行列の転置：ベクトルや行列の文字の左上にレギュラー小文字斜体のtを置く．TeXで書くと\mbox{}^t\bm{a}のようになる．
一次結合・一次関係・一次従属・一次独立：教科書は全て「一次」を使う．線形結合・線形関係・線形従属・線形独立は「こういう言い方もある」という形で言葉として紹介するのみ．なお，一次関係とは一次結合=\bm{0}とおいた方程式のこと．但し，写像だけは「線形写像」を使う（「一次写像」は紹介にとどめる）．
span：span自体には教科書には登場しない．その代わり，「ベクトル\bm{a}_1と\bm{a}_2が生成する空間」という言い方で表現している．但し，spanという言葉や「\bm{a}_1と\bm{a}_2が張る空間」という言い方は知っておくべきなので，紹介はしているし，教科書の範囲は超えるがこのアプリではspanを採用して「ベクトルが生成する空間＝span」という関連性を覚えてもらうのも良いかもしれない．ベクトル\bm{a}_1と\bm{a}_2からなる選択集合をS = \{\bm{a}_1, \bm{a}_2\}と表すとき，\mathrm{span}(S) \subseteq Vのような数学表現が望ましい．但し，よく見かける表記の\mathrm{span}(\bm{a}_1, \bm{a}_2)でも良いと思う（どちらも理解してほしい）．なお，授業では\mathrm{span}(S)を，ブラケットを使って\langle \bm{a}_1, \bm{a}_2 \rangleと表している（内積の表記との混同には都度注意する）．
rank：行列\bm{A}に対して，\mathrm{rank}(\bm{A})=3のように定義している．\mathrm{rank}()は行列を引数とし0以上の整数を返り値とする演算，ということになる．但し，後述の通り写像Tを引数とするrankも登場する．
dim：ベクトル空間Vに対して\mathrm{dim}(V)=3のように，ベクトル空間を引数，0以上の整数を返り値として定義され，そのベクトル空間の次元となる．rankとの混同には注意して欲しい．例えば，S = \{\bm{a}_1, \bm{a}_2, \bm{a}_3\}という3個の要素を持つベクトル集合Sが生成する空間\mathrm{span}(S)の次元は，行列\bm{A} = [\bm{a}_1 \bm{a}_2 \bm{a}_3]を用いて\mathrm{dim}(\mathrm{span}(S)) = \mathrm{rank}(\bm{A})といえる（\mathrm{span}(S)の次元は\bm{A}の列ベクトルの一次独立な最大個数に一致するため，すなわち行列のランクは、その列ベクトルが生成する列空間の次元に等しい）．
一次独立な最大個数：n個のベクトル\bm{a}_1, \bm{a}_2, ..., \bm{a}_nからm個を選んだとき、そのm個が一次独立となるような最大のmのこと．
一次独立の定義：\bm{v}_1, \bm{v}_2, ..., \bm{v}_nが一次独立とは，係数c_1, c_2, ..., c_n \in \mathbb{R}を用いて作ることのできる\bm{v}_1, \bm{v}_2, ..., \bm{v}_nの一次関係が，係数c_1 = c_2 = ... = c_n = 0でしか成立しないということ．学生はこの定義式が直観的には「ベクトルの平行」や「2個のベクトルが張る平面上に3個めのベクトルが乗っている」というような幾何学的な定義になかなか結び付かない．「全ての係数が0でしか一次関係を成立させられない」ということが，係数c_m \neq 0で一次関係の両辺を割って\bm{v}_m = ...という形（\bm{v}_m以外のベクトルの一次結合）で表せない，ということを理解させられるとよい．この「一次独立の数学的定義」と「一次独立の幾何学的意味」のギャップを，このWebアプリで埋められるとなお良い（基本的なアプリが完成した後に，このギャップに関するページを追加する形が良いかもしれないが，もっと統合的な形で教えられるならばそれでも良い）．
集合と組：集合\{\bm{v}_1, \bm{v}_2, \bm{v}_3\}と組(\bm{v}_1, \bm{v}_2, \bm{v}_3)（但し括弧は省略するときもある）はできるだけ厳密に分けたい．集合は順序に依存せず，組は依存する．なので\mathrm{span}(\{\bm{v}_1, \bm{v}_2, \bm{v}_3\})は集合\{\bm{v}_1, \bm{v}_2, \bm{v}_3\}に対して定義したい（組(\bm{v}_1, \bm{v}_2, \bm{v}_3)に対して定義もできるが，spanにベクトルの順序依存性はないのであまり好ましくない表記，と言いたい）．
ベクトルの組を用いた一次結合の表現：ベクトルの組(\bm{u}_1, \bm{u}_2, ..., \bm{u}_n)の一次結合は，一次結合係数をまとめた列ベクトル\bm{c} = \mbox{}^t[c_1, c_2, ..., c_n]を用いて(\bm{u}_1, \bm{u}_2, ..., \bm{u}_n)\bm{c}と表す．組と列ベクトルを行列積のように計算していることに相当する．また，この表記方法の拡張で列ベクトルを行列\bm{C}にすることで，\bm{C}の各列を一次結合係数とした組を計算でき，例えば(\bm{w}_1, \bm{w}_2, ..., \bm{w}_n) = (\bm{u}_1, \bm{u}_2, ..., \bm{u}_n)\bm{C}と表記する．このとき，組と組の等号(\bm{a}_1, \bm{a}_2, ..., \bm{a}_n) = (\bm{b}_1, \bm{b}_2, ..., \bm{b}_n)は「\bm{a}_i = \bm{b}_iが全てのiについて成立すること」を意味している．この一次結合の表記は教科書でも授業でも頻出となるため，授業でもよく理解してもらう必要がある．Webアプリにおいても，この表記が一次結合であることを理解させる題材があるとよいかもしれない．
標準基底の順番：数ベクトルの場合は当然\bm{v}_1 = \mbox{}^t[1, 0, 0]，\bm{v}_2 = \mbox{}^t[0, 1, 0]，\bm{v}_3 = \mbox{}^t[0, 0, 1]という順番で自然に定義する．一方で，高々n次多項式空間の基底は(1, x, x^2, ..., x^n)のように昇べきの順で0次からn次に向かう順序で定義する．
行列の簡約化：特に断りがない限り行簡約化を取り扱う（RREF行列を基準とする）．このとき，RREF行列の各非零行の左端の非ゼロ要素を「主成分」と呼ぶ．
連立方程式関連：一般的な連立一次方程式を\bm{A}\bm{x} = \bm{b}と定義し，\bm{A}を係数行列，\bm{x}を変数ベクトル，\bm{b}を定数ベクトルと呼ぶ．また，\bm{A}の右端の列に\bm{b}を1列追加したものを拡大係数行列と呼び[\bm{A} \mid \bm{b}]と表記する．さらに，\bm{A}\bm{x} = \bm{0}を同次形連立一次方程式と呼ぶ．解が無数にある場合を「不定」，解が存在しない場合を「不能」，解が一意に定まる場合を「唯一解」と呼ぶ．同次形連立一次方程式の\bm{x} = \bm{0}を自明解と呼ぶ．
ベクトル空間と部分空間：ベクトル空間Vに対して，WがVの部分空間になっている（W \subseteq V）ことの必要十分条件は，(1) \bm{0} \in W（Wは零ベクトルを元として含む），(2) \bm{u}, \bm{v} \in Wならば\bm{u} + \bm{v} \in W（Wは和について閉じている），(3) \bm{u} \in Wかつc \in \mathbb{R}ならばc\bm{u} \in W（Wはスカラー倍について閉じている）の全てが成立することである．
写像の表記：写像は原則Tを使う．T_1のように添え字をつけることもある．ベクトル\bm{u}の像はT(\bm{u})のように表記する．Tが\mathbb{R}^3から\mathbb{R}^2の線形写像であるならば，T: \mathbb{R}^3 \rightarrow \mathbb{R}^2と表記し，さらにこれは行列\bm{A} \in \mathbb{R}^{2 \times 3}を用いてT(\bm{u}) = \bm{A}\bm{u}と表せる．これを，「行列\bm{A}による写像」という意味を持たせてT_{\bm{A}}と表記することも多い．
線形写像の像と核：写像Tの像を\mathrm{Im}(T)，核を\mathrm{Ker}(T)と書く．
線形写像のランクと退化次数：写像Tのランクを\mathrm{rank}(T)，退化次数を\mathrm{null}(T)と書く．線形写像T_{\bm{A}}については，\mathrm{rank}(T_{\bm{A}}) = \mathrm{rank}(\bm{A}) = \mathrm{dim}(\mathrm{Im}(T_{\bm{A}}))，\mathrm{null}(T_{\bm{A}}) = n - \mathrm{rank}(\bm{A}) = \mathrm{dim}(\mathrm{Ker}(T_{\bm{A}}))といえる（nは\bm{A}の列数）．TがT: U \rightarrow Vなる線形写像であれば，次元定理は\mathrm{dim}(U) = \mathrm{rank}(T) + \mathrm{null}(T)と書ける．
表現行列：T: U \rightarrow Vなる線形写像において，Uの基底(\bm{u}_1, \bm{u}_2, ..., \bm{u}_n)とVの基底(\bm{v}_1, \bm{v}_2, ..., \bm{v}_m)を定義する．このとき，(T(\bm{u}_1), T(\bm{u}_2), ..., T(\bm{u}_n)) = (\bm{v}_1, \bm{v}_2, ..., \bm{v}_m)\bm{A}が成立するならば，行列\bm{A}を「Uの基底(\bm{u}_1, \bm{u}_2, ..., \bm{u}_n)とVの基底(\bm{v}_1, \bm{v}_2, ..., \bm{v}_m)に関するTの表現行列」と呼ぶ．表現行列は写像前と写像後の基底やその順序に依存するものであるため，「Uの基底(\bm{u}_1, \bm{u}_2, ..., \bm{u}_n)とVの基底(\bm{v}_1, \bm{v}_2, ..., \bm{v}_m)に関する」という長い枕詞がつく．
線形変換：T: U \rightarrow Uのように同じ空間にベクトルを写像する線形写像を線形変換と呼ぶ．「ベクトル空間Vの線形変換T」はT: V \rightarrow Vの意味である．
固有値と固有ベクトルの表記：T: \mathbb{R}^n \rightarrow \mathbb{R}^nなる実数体上の線形変換Tに対して，T(\bm{u}) = \lambda \bm{u}を満たす\lambda \in \mathbb{R}をTの固有値，\bm{u}（但しゼロベクトル以外）をTの固有ベクトルと呼ぶ．この時，本授業では実数体上の線形変換Tの固有値として非実複素数は扱わない．もしT_{\bm{A}}に対して行列\bm{A}が実固有値を持たない場合は，実数体上の線形変換T_{\bm{A}}の固有値はない，ということになる．行列に対しては非実複素数も固有値として扱うことが一般的であるが，本授業では実数体上の線形変換に対する固有値は\lambda \in \mathbb{R}として定義する．
固有空間：ベクトル空間Vの線形変換Tにおいて，\{\bm{u} \in V \mid T(\bm{u}) = \lambda \bm{u}\}を「Tの固有値\lambdaに対する固有空間」と呼び，W(\lambda; T)と表記する．W(\lambda; T)はVの部分空間となる．これはすなわち「\lambdaに対応する固有ベクトルが張る部分空間」である．固有ベクトルはゼロベクトルではないが，固有空間はゼロベクトルを含む点に注意である．
固有多項式：線形変換Tが正方行列\bm{A}によりT(\bm{u}) = \bm{A}\bm{u}と表されるとき，g(\lambda) = |\bm{A} - \lambda \bm{E}|を固有多項式と呼び，|\bm{A} - \lambda \bm{E}|=0を固有方程式と呼ぶ．ここで，\bm{E}は\bm{A}と同じサイズの単位行列である．
