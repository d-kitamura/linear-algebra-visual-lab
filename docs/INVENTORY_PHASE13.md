## 実装・仕様・検証の対応

| 点検対象 | 確認した境界 |
|---|---|
| 6Labの状態分離 | Appは各Labを保持し、URLのlabで初期表示を選ぶ。6固定URL・88代表URLで他Labの初期化が既定値のままであることを検証 |
| 第六Labの7場面 | 数ベクトル0〜3D、多項式1〜3Dを別slotに保持。多項式0Dは作らず、0Dからの切替は直近の多項式次元。Resetは現在slotの起動時状態のみ |
| 対角化の前提 | 実数体・自己写像・入出力に同じ基準基底。異なる基底を使う一般の表現行列と混同しない |
| 数学的な不可と保留 | 非実根／固有ベクトル不足による不可、根・空間の未確認、Pの構成／検算の不安定、入力座標だけの失敗を分離。未確認空間を0次元と数えない |
| P・D・座標 | 固有列は実根昇順・空間内順、符号付き最大成分で正規化。AP=PD、両側の逆行列、Pc、PDc、独立に解く像座標とDcを検算。列順交換は固定自動順への絶対的な置換 |
| 数値基準 | 相対ピボット1e-10、条件数κ∞≤1e8、固有列／AP=PD残差1e-12、逆行列残差1e-8、座標残差1e-10を維持。有理数LUを再利用し、入力ドラッグで根・分解を再計算しない |
| 0D・1D・多項式 | 0Dは空基底・空行列で形式的に対角化し、固有値0を捏造しない。定数多項式は1D。多項式自体、標準単項式係数b、固有基底座標cを区別 |
| 描画と編集 | 左の入力のみ直接編集。右は同じ入力・像のc／Dcであり矢先は読取専用。2D幅2%・3D幅3%の吸着、原点優先。固有空間は別々に扱い、初期は非表示 |
| ドラッグ中の連動 | 確定sceneとpreviewを分離。2Dの表示範囲を固定し、3Dは確定vectorsを構築入力・複数previewを差替え入力にする。像・c・Dcのリアルタイム連動とラベル残留防止の既存回帰を維持 |
| 描画上限 | 成分の絶対値100万を超す導出座標は切り捨てず、図だけを保留。数値化不能の像を偽の零へ置換せず、数値編集・解析から復帰できる |
| 共有 | 独立diagonalization v1。現在の行列・入力・列順・表示と左右3Dカメラを保存。0Dは3キーのみ。P/D・解析・下書き・タブ・他slot・1D/2D手動範囲は保存しない |
| 共有の再現性 | 構造層は数学解析を呼ばず、対象Lab復元時に基底の有無とorderを照合。不整合を黙って自動順へ修復しない。再エクスポートでReset基準を更新しない |
| 既存wire | vector-space v4、basis-dimension v2、linear-map v2、representation-matrix v1、eigenspace v1は不変。正式リリース／互換保証は未開始 |
| 表記・配置 | ベクトル文字のみ太字斜体・添え字は立体、角括弧と転置表記、T(f(x))とxf′(x)。全Labの黒い3D軸、上部見出しと操作位置、タブ、対角化2図の非stickyを維持 |
| 授業資料・代替導線 | 88例はMarkdownに置き、常設の課題・独立要約パネルは追加しない。成分ラベル・3タブ参照・キー接続・狭幅CSS・WebGL代替を検証。実機の読上げ品質は自動検証と区別 |

正本は[詳細設計](./DIAGONALIZATION_LAB_DESIGN.md)、[API契約と実装記録](./DIAGONALIZATION_API_CONTRACT.md)、[教員用18例](./DIAGONALIZATION_TEACHING_GUIDE.md)。数学テストは `tests/domain/diagonalization.test.ts` と `diagonalizationNumerics.test.ts`、画面・状態・共有は対角化関連のUI／sharingテストを参照する。

## 次の単元への引継ぎ（棚卸し時点の記録）

D-124承認後、[フェーズ14設計案](./INNER_PRODUCT_LAB_DESIGN.md)を作成した（D-125確認待ち・実装未着手）。以下は棚卸し時点で整理した検討事項。

シラバス第15週の**内積・正規直交基底・グラム・シュミット法**が次の候補。別途詳細設計を依頼された時点で工程化し、この棚卸しでは新Labやフェーズ番号・仕様を確定しない。ケイリー・ハミルトン／次数落としを再導入しない。

1. ユークリッド内積を最初の対象にするか、多項式の内積も扱うかを決める。係数列の内積と多項式の積分による内積は同じではなく、単なる係数空間の図から同一視しない。
2. 投影、直交成分、正規化の順を視覚化する範囲と、基底順序依存を設計する。零ベクトル・一次従属・ほぼ従属での失敗を区別する。
3. グラム・シュミットの教材上の手順と、計算に用いる安定化／残差の基準を分けて決める。現在の対角化の固有列を勝手に直交化しない（異なる固有空間は一般に直交しない）。
4. 共通0D〜3D表示・数値編集・ラベル・共有ダイアログを再利用し、独立状態・Reset・URLの範囲を先に定義する。授業例は引き続きMarkdownを基本とする。

次の詳細設計には**「高」推奨**。内積の定義、直交化の数値境界と幾何表示を横断して決めるため。既存Labの操作改善だけを依頼された場合は、その規模に応じて「中」で進められる。
