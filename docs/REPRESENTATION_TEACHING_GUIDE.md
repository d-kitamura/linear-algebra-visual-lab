# 表現行列Labの授業導線（11.8）

最終更新: 2026-09-08

シラバス10〜11週の「基底による行列表示」「低次元の表現行列」に対応する。状態と独立に求めた期待値の正本は`src/teaching/representationMatrixScenarios.ts`。既存41例を変更せず11例を追加し、計52例とする。固有値・対角化はここでは扱わない。

## 授業での手順

1. 表現行列Labの「授業用の代表例と観察課題」を開き、例を選ぶ。指定先の種類・次元・モードの場面だけが置き換わる。
2. まず期待値の折りたたみを開かずに、写像と入力が同じか、両基底と順序は何か、各列は何の座標か、変換方向はどちらかを問う。
3. 「表現行列の作り方」と「座標での作用」を確認し、期待値と比較する。図を利用できない場合は「現在の状態の読み上げ要約」を使う。
4. 教員はURL・QRをエクスポートして配布し、学生は別タブで開く。基底または入力を変更して比較した後、Resetで配布状態へ戻る。

例を選ぶ操作自体は起動時のReset基準を変更しない。教員のタブでResetすると、その場面の起動時状態へ戻る。配布したURLを開いた学生のタブでは、配布状態がReset基準となる。課題・例名・開いている説明はURLへ追加しない。

## 観察順と期待

最初の4例は同じ写像・入力・像で、基底だけが異なる。入力の基準成分は上から3,2、像は上から5,2である。

| 例 | 主な観察点・期待 |
|---|---|
| 標準基底同士 | 表現行列は基準行列と一致。入力座標は上から3,2、像の座標は5,2 |
| 同じ非標準基底 | 両側とも第2基底を2倍。表現行列の第1行は1,2、第2行は0,1。入力座標3,1、像の座標5,1 |
| 異なる2基底 | 表現行列の第1行は1,2、第2行は−1,−1。入力座標1,2、像の座標5,−3 |
| 基底の順序交換 | 標準基底の定義域だけ順序交換。表現行列の列が入れ替わり、入力座標は2,3。像は不変 |
| 1Dの長さと向き | 写像は3倍、定義域の基底は2、終域の基底は−1。表現行列は−6、入力座標2、像の座標−12、像の基準成分12 |
| 2Dから3Dへの埋め込み | 3行2列。像の基準成分3,2,0。像が平面内でも終域の次元は3 |
| 3Dから2Dへの射影 | 2行3列。第3列は零。入力3,2,1の像は3,2 |
| 恒等写像による基底変換 | 基準行列は単位行列。正方向の変換行列の行は1,1と−1,0。座標1,2が3,−1へ変わるが、対象自体は不変。逆方向も確認 |
| 基底でない候補 | 定義域の候補は一次従属。表現行列・基底座標は未確定だが、基準行列で像5,2は求められる |
| 多項式の微分 | 入力は1+2x+3x²、像は2+6x。像の基準係数は2,6、選択基底での座標は−4,6 |
| 多項式への変数の乗算 | 入力は1+2x、像はx+2x²。基準係数は0,1,2。表現行列は3行2列 |

数式の画面表示は既存の数式部品を共用する。多項式の係数と基底座標を混同せず、入力と像を常に基準成分と区別する。期待値は解析結果から生成せず、テストで独立に照合する。

## 図を使わない確認とキーボード

- 「現在の状態の読み上げ要約」は全タブに共通し、空間・基準行列・基底順と成分・rank・基底不成立理由・入力と像・表現行列の各列・2経路・恒等写像の方向を文章で示す。
- 数値が丸められる場合は「約」を付ける。数値計算失敗と基底不成立を区別し、未確定の結果や経路一致を断言しない。
- ドラッグ中も要約を更新するが、ライブ通知を連続発火させない。必要な時に折りたたみを開いて読む。
- Tabで例・種類・次元・成分・順序変更ボタンへ移動できる。詳細タブは左右矢印・Home・Endで移動する。数値入力のEscapeは現在の確定値へ戻す。共有ダイアログはEscapeで閉じる。
- 390px幅では代表例の選択欄をカード幅内に収め、要約の長い内容は折り返す。Canvas/WebGLを利用できなくても入力・解析・要約・共有操作を残す。
