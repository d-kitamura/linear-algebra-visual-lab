## 1. 教材範囲

- 第四のLabを「表現行列・基底変換Lab」、識別子を`representation-matrix`とする。既存線形写像Labの行列記号や操作は変更しない。
- シラバス第10〜11週の「基底による線形写像の行列表示」「具体例から表現行列を求める」を扱う。
- 通常操作は定義域・終域が各1〜3次元の9次元組。数ベクトルと高々0〜2次の多項式を扱う。多項式空間の次元は最高次数＋1であり、定数多項式空間は1次元、零空間とは異なる。
- 各空間の種別は独立とする。多項式→数ベクトルなども標準座標間の行列作用として定義できるが、主な授業例は数ベクトル同士・多項式同士とする。
- 0Dは空の基底・空行列の補助説明と既存線形写像Labへの導線に限定し、新Labの通常操作セレクタへ追加しない。数学APIは0D境界も扱える設計にする。
- 高次元、文字式の自由入力・構文解析、非線形写像、関数グラフ、分数・根号の復元、固有値・対角化は対象外。

## 2. 採用する記号

| 対象 | 採用記号・表示 |
|---|---|
| 空間・写像 | \(T:U\to V\) |
| 定義域基底 | \(\mathcal B=(\bm u_1,\ldots,\bm u_n)\) |
| 終域基底 | \(\mathcal C=(\bm v_1,\ldots,\bm v_m)\) |
| 基準となる基底 | \(\mathcal E_U,\mathcal E_V\)：数ベクトルは標準基底、多項式は標準単項式基底 |
| 写像の固定定義 | \(\bm M\)：基準となる2基底に関する行列 |
| 現在の表現行列 | \(\bm A\)：見出しに「基底 \(\mathcal B\) から基底 \(\mathcal C\) に関する \(T\) の表現行列」と明記。複雑な添え字略記は導入しない |
| 入力・像 | \(\bm w\)、\(T(\bm w)\)。基底の \(\bm u_i,\bm v_j\) や多項式変数 \(x\) と区別する |
| 入力・像の座標 | \(\bm c=[\bm w]_{\mathcal B}\)、\(\bm d=[T(\bm w)]_{\mathcal C}\)。単に \(\bm c,\bm d\) とだけ書かず、どの基底の座標かを併記 |

主式は授業の定義を維持する。

\[
(T(\bm u_1),\ldots,T(\bm u_n))=(\bm v_1,\ldots,\bm v_m)\bm A,
\qquad \bm d=\bm A\bm c.
\]

各列は \(T(\bm u_i)=a_{1i}\bm v_1+\cdots+a_{mi}\bm v_m\) を解いて得た係数列である。組は丸括弧、行列・列ベクトルは角括弧を使い分ける。\(\bm M\)も表現行列の一つであり、「写像そのもの」や「基底に依存しない行列」と説明しない。

\[
[T(\bm w)]_{\mathcal E_V}=\bm M[\bm w]_{\mathcal E_U}.
\]

基底編集では\(\bm M\)と基準座標で保存した入力を変えない。\(T\)と\(T(\bm w)\)を固定したまま、\(\bm A,\bm c,\bm d\)の変化を比較できる。写像編集は\(\bm M\)を変更する操作として明確に分離する。

## 3. 基底変換の向き

同一の空間における恒等写像の表現行列を、次の記号で表示する。

\[
\bm P_{\mathcal C\leftarrow\mathcal B}[\bm w]_{\mathcal B}
=[\bm w]_{\mathcal C},
\qquad
(\bm u_1,\ldots,\bm u_n)
=(\bm v_1,\ldots,\bm v_n)\bm P_{\mathcal C\leftarrow\mathcal B}.
\]

見出しは「基底Bの座標 → 基底Cの座標」。左から行列を掛ける列ベクトル規則を維持する。逆向きは\(\bm P_{\mathcal B\leftarrow\mathcal C}\)であり、両者の積は単位行列\(\bm E\)となる。ベクトルの組を右から変換する式と、座標列を左から変換する式の向きを取り違えないよう併記する。

基底変換モードは同じ次元・同じ空間種別に限定し、\(T\)を恒等写像に固定する。数ベクトルと多項式の間の係数対応は同型だが、異なる空間同士の恒等写像とは呼ばない。

## 4. 数値例による方向の確認

数ベクトルの例：

\[
\bm M=\begin{bmatrix}1&1\\0&1\end{bmatrix},\quad
\mathcal B=\left(\begin{bmatrix}1\\0\end{bmatrix},\begin{bmatrix}1\\1\end{bmatrix}\right),\quad
\mathcal C=\left(\begin{bmatrix}1\\1\end{bmatrix},\begin{bmatrix}0\\1\end{bmatrix}\right).
\]

\[
\bm A=\begin{bmatrix}1&2\\-1&-1\end{bmatrix},\quad
\bm w=\begin{bmatrix}3\\2\end{bmatrix},\quad
\bm c=\begin{bmatrix}1\\2\end{bmatrix},\quad
\bm d=\begin{bmatrix}5\\-3\end{bmatrix},\quad
T(\bm w)=\begin{bmatrix}5\\2\end{bmatrix}.
\]

同じ2基底で恒等写像に変えた場合は
\(\bm P_{\mathcal C\leftarrow\mathcal B}=\begin{bmatrix}1&1\\-1&0\end{bmatrix}\)。
\([\bm w]_{\mathcal B}=\mbox{}^t[1,2]\)から\([\bm w]_{\mathcal C}=\mbox{}^t[3,-1]\)へ変換し、ベクトル自体は変わらない。

多項式の例：微分\(D:\mathbb R[x]_2\to\mathbb R[x]_1\)、\(\mathcal B=(1,x,x^2)\)、\(\mathcal C=(1,1+x)\)。

\[
\bm M=\begin{bmatrix}0&1&0\\0&0&2\end{bmatrix},\quad
\bm A=\begin{bmatrix}0&1&-2\\0&0&2\end{bmatrix}.
\]

入力\(\bm w=f(x)=1+2x+3x^2\)に対し、\(\bm c=\mbox{}^t[1,2,3]\)、\(\bm d=\mbox{}^t[-4,6]\)。像は\(-4+6(1+x)=2+6x\)であり、基準係数\(\mbox{}^t[2,6]\)と選択基底の座標\(\mbox{}^t[-4,6]\)を区別する。

## 5. 状態・操作・共有の境界

| 保存する状態 | 内容 |
|---|---|
| 場面のキー | 定義域次元・終域次元・各空間種別・通常／基底変換モード。切替後も場面ごとに独立保持 |
| 写像 | 基準座標に対する\(m\times n\)行列\(\bm M\)。JSON内部は行配列 |
| 基底候補 | 各ベクトルの基準座標列を順序通りに保存。通常は定義域n本・終域m本。数値編集・順序交換・ドラッグが可能 |
| 入力 | 基準座標列として保存。基底を変えても入力のベクトル／多項式自体は変わらない |
| 表示設定 | 教材上の表示スイッチと、3D側だけのカメラ。手動1D/2D表示範囲は共有しない |

基底候補は編集中に一次従属でも保存可能とする。ただし基底でない状態では表現行列・座標・逆変換を未確定として表示し、以前の計算値を有効な値のように残さない。標準座標での写像と像は、基底が成立しなくても計算・表示できる。

内部の数学APIは本数不足・過剰も不正な基底として理由を返す。授業画面で本数を自由に増減させる機能は設けず、候補選択の教材は既存基底・次元Labへ委ねる。

表現行列、座標、像、rank、基底判定、多項式の文字列表現、経路一致は派生値であり共有しない。手動1D/2D範囲、詳細タブ、入力下書き、ドラッグ途中状態も共有しない。

共有は既存3Labから独立した`representation-matrix` v1で、現在の場面だけを保存する。Resetはその場面の共有時InitialStateへ戻す。他の場面・Labには影響させない。共有の本実装は11.7であり、11.3〜11.6では誤って既存Labの状態を出力しない。

完全URL2048文字・受信8192文字と有限値・成分上限を維持する。新Labは2基底を持つため、最大3D場面のURL長を11.7で必ず検証する。超過時は既存同様に理由を示し、基底・入力・写像を黙って丸めたり省略したりしない。安全な短縮形式が必要なら別途提案する。
