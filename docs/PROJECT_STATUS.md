## 既知のリスクと後続確認

- D-014 の提案では、手動ズーム後は表示範囲を維持し、「全体を表示」で自動追従へ戻す。この切替規則は利用者確認待ちである。
- 自動スケールの余白率、目盛密度、手動ズームの倍率上下限と感度は、2.2・2.3 の操作確認で調整する。
- 2D の手動表示範囲を共有する場合、現行 v1 の厳密なスキーマを変更せず、次版と後方互換の読込方針を定義する必要がある。
- D-009 の相対許容誤差は、2D の直接操作と操作感を確認した後に再評価する。
- D-010 の 8192 文字は防御上限であり、学内サーバー、LMS、スライド等で保証される URL 長ではない。
- GitHub Pages のプロジェクトサイトでは、ビルド時にリポジトリ名のサブパスを `APP_BASE_PATH` へ指定する必要がある。
- nginx の既定構成では一つのリクエスト行が 8 KiB を超えられないため、共有 URL の実用上限は防御上限より短くなる可能性がある。
- URL クエリーパラメーターへの接続、不正 URL の画面表示、Reset はフェーズ 2 の後続作業で実装する。
- 3D カメラ状態を共有対象へ含めるかは 3D 実装時に判断する。
