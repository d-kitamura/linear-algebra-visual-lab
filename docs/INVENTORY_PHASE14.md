## 結論・今回の補修

実装の照合と自動検証の範囲では、新たに補修を要する実行時の不具合は見つからなかった。数学API・画面・共有形式・依存は変更しない。これは実機検証や、全入力に対する無欠陥の保証ではない。

- 統合回帰が6Lab・88例のままだったため、7Lab・106例へ拡張。7固定URLの対象Labだけの初期化、QR生成、第七Labで内積・入力順・成分・pair・モード・段階・視点を編集した後の共有時Resetを追加した。既存88例とfixtureは変更しない。
- README・進捗・工程・決定の現在地を更新。重複した承認履歴を現在地から整理し、個別D記録は残した。古い工程の検証件数・当時の未着手記録は履歴であって現在の状態ではない。
- 配布ガイドに第七Labと106例、内積の図と共有／Resetの注意を追加。互換方針の版一覧に抜けていたinner-product v1を追加し、統合回帰の説明を7Labへ更新した。
- 利用案内の対象と保存する状態を7Labへ更新。有理数による零判定と数値化・検算の保留を区別した。SPECの「URL上限未決定」「共有14.7予定」の残存記述を現行仕様へ揃え、版を1.44へ更新した。

## 実装・契約・検証の対応

| 対象 | 確認した境界と検証先 |
|---|---|
| 7Labの分離 | Appは各Labを独立保持し、非表示Labの描画を停止。共有labで初期表示を選択する。`tests/integration/multiLabRegression.test.ts`で7固定URL・106例の他Lab非干渉を検証 |
| 内積Labの7場面 | 数0〜3D・多項式1〜3Dを独立保持。切替時に他場面を上書きしない。Resetは現在slotだけの起動時snapshotへ戻す。`innerProductDimensions`／`innerProductPolynomial`／`innerProductSharing`の各テストを照合 |
| 内積・射影 | 数はユークリッド内積。多項式は既定の区間[-1,1]の積分と係数内積を区別。vをu方向へ射影し、u=0ならp=0・r=v、零との角度は未定義。独立な積分・手計算期待値と照合 |
| グラム・シュミット | 元入力aから採用済みの非零直交wへの射影を引き、残差を正規化。表示を段階分割しても計算経路は同じ。固定sourceIdと処理順／出力番号を分離。順序変更で入力を改名しない |
| WとV | 完了したQはまずW=span(S)の正規直交基底。Vの基底は採用数が周囲次元に等しい場合だけ。空入力・全零はWの空基底。0Dだけは空基底がVの基底でもある。保留時は完成基底と断定しない |
| 零と数値保留 | 入力binary64値の有理数による厳密な零残差だけをスキップ。微小非零を1e-10等で従属へ丸めない。数値化／正規化で成分が失われたら保留し、後続段階を捏造しない |
| 予算・検算 | 有理数32768bit・一時65536bit、20000演算・200000剰余、直交単位／再構成／成分検算1e-12を維持。独立期待値と予算注入、極小値・非整数8本を回帰。既存固有値・対角化の有理数APIの回帰も全体実行に含む |
| 内積と図 | 積分時は固定z=Cb、転置C×C=G。元係数bと図のξ軸、GSで得るQは別物。逆変換・往復残差を検査し、原点吸着は元係数も厳密零にする。係数内積なら係数軸bを使う |
| 編集と描画 | 元入力のみ編集。原点吸着だけを使用し、方向吸着はしない。1D/2D表示幅2%、3D3%。下書き・ドラッグpreviewと確定sceneを分離。3D派生slotは固定IDのまま差し替えて、古いラベルや図を残さない |
| 描画上限 | 元入力と変換後の描画上限を区別。有限でも表示成分が100万を超えた場合は図だけ保留し、成分・解析を維持。逆変換できない候補を数式だけへ適用しない |
| 共有 | 独立inner-product v1。ID／順序・内積・pair・モード・段階・補助図・3Dカメラを保存。0Dは4項目、正次元の空入力とは別。G/C・p/r/q・解析・下書き・他slot・手動1D/2D範囲を保存しない |
| 共有の再現性 | 構造層はGSを呼ばず、対象Lab復元時だけavailableStagesの存在を厳密照合。無効段階を先頭へ修復せず警告と既定例へ退避。再共有でReset基準を変更しない |
| 既存形式 | vector-space v4、basis-dimension v2、linear-map v2、representation-matrix／eigenspace／diagonalization v1は不変。旧固定URLの復元も維持。正式な互換保証はまだ開始しない |
| 表記・配置 | ベクトル文字のみ太字斜体、添え字は立体。多項式自体・標準係数・選択基底座標を区別。7Lab共通の見出し／操作、黒い3D軸、解析タブを維持。課題一覧・独立要約パネルを追加しない |
| 授業資料・代替操作 | 106例をMarkdownへ集約。18内積例の独立期待値、読み上げラベル、タブ・段階キー接続、狭幅CSS、WebGL代替を回帰。SSR・ソース検査は実機の発音・レイアウト・操作確認の代替ではない |

## 第15週への対応と範囲外

[syllabus.txt](../syllabus.txt)第15週の「内積を説明する」は、成分積の和、ノルム・角度・射影、多項式の積分／係数内積比較で扱う。「グラム・シュミットで基底を正規直交化する」は、元入力→射影→残差→正規化の各段階、順序依存、生成空間と周囲空間の基底の区別で扱う。

授業での学習効果は未評価であり、機能・回帰の完成と教育効果の実証は分ける。フェーズ7の再開は別途指示を待つ。任意の内積行列、複素内積、高次元、記号式／根号の復元、ケイリー・ハミルトン・次数落としは対象外。次単元や新フェーズをこの棚卸しで追加しない。
