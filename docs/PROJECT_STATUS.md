## 既知のリスク

- rank 判定の許容誤差を決めないまま UI を作ると、視覚表示と数学的判定が矛盾する可能性がある。
- 共有状態を後付けすると、描画内部の一時状態へ依存し、URL の再現性が崩れやすい。
- 3D のベクトル編集とカメラ操作はジェスチャーが競合するため、2D と同じ操作をそのまま採用できない可能性がある。
- 学内サーバーのベースパスや URL 書き換え条件によって、ルーティングと共有 URL の設計が影響を受ける。
