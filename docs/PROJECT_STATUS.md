## 作業単位 2.4 の変更

- 矢印先端へ見た目より広い透明な操作領域を追加し、マウス、ペン、タッチでベクトルを直接編集できるようにした。

- 先端の操作領域と背景のパン・ピンチ領域を分け、先端ドラッグ中はホイールズームを含む表示操作を開始しないようにした。
- 自動表示ではドラッグ開始時の表示範囲を固定し、終了後に全体へ再フィットする。手動表示では利用者の表示範囲を維持する。

- 他の非零ベクトルが張る直線へ画面幅 `1%` 以内まで近づくと、最も近い直線へ先端を直交射影する平行スナップを追加した。表示倍率に応じて数学座標上の距離を比例変更する。
- 平行スナップ中は先端の操作円と吸着先の矢印を形状・太さで強調する。D-009 の rank 判定閾値 `1e-10` は変更していない。
- 数値入力欄をキーボード操作の代替手段として維持し、画面内の操作説明を先端ドラッグと背景ドラッグの区別が分かる文へ更新した。
- 生成する空間の幾何表示と共有 UI は追加していない。
