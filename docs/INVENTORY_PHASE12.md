## 依存関係・配布

- package.json・lockfile・第三者通知のブラウザ実行時依存を照合。qrcode 1.5.4、React／React DOM 19.2.8、scheduler 0.27.0、Three.js 0.185.1、dijkstrajs 1.0.3はMIT通知と一致。固有値解法は新規依存なし。今回はオンラインの脆弱性監査やパッケージ更新は行っていない。
- GitHub Actionsはmainのpush→固定lockfileでinstall→test→build→静的成果物検査→dist公開。`APP_BASE_PATH=/linear-algebra-visual-lab/`と検査用`EXPECTED_BASE_PATH`が一致し、実際のPages用成果物をローカル検査した。共有URLは現在のorigin/pathから生成する。
- nginxも静的dist配布という契約は不変。実際に採用する際のTLS・URL長・WAF等は[nginx手順](./NGINX.md)で確認する。学内実環境の確認は今回行っていない。
- 主JS約501.11kB（gzip約137.50kB）と遅延3D chunk約580.04kB（gzip約147.95kB）に500kB超の警告がある。ビルド失敗ではないが、実機の初期表示・3D初回読み込み速度は確認対象。警告閾値の引上げや安易な分割は行わず、問題があれば別作業で測定・最適化する。

## フェーズ13への引継ぎ

次はシラバス第13〜14週に向けた**詳細設計**。対角化・Cayley–Hamiltonの実装や新しい共有スキーマは本作業に含めない。

1. `analyzeEigenMap`の確認済み根・重複度・固有空間を再利用する。実数体上の対角化可能性を、固有空間の次元の総和・独立な固有ベクトルの個数へ接続する。ただし、空間がnull・根集合が不完全・方向が不安定な場合は「判定保留」であり「対角化不可」の根拠にしない。必要な条件と数値検証は詳細設計で定める。
2. 第四Labの一般の表現行列は入出力の基底が異なり得る。それを無条件に固有値／対角化へ渡さない。同じ順序付き基底で表す自己写像という前提と、変換方向を明示する。
3. 固有空間の基底の一例は符号・順序・長さが唯一ではない。固有ベクトルから作る行列Pと対角行列の対応、AP=PDの残差、Pの独立性／条件の確認、入力座標の対応を設計する。図の見た目だけで逆行列の存在を保証しない。
4. 固有多項式はdet(A−λE)、API係数は低次から、最高次係数は(−1)^n。Cayley–Hamiltonへ渡す際に順序・符号を取り違えず、行列多項式の残差と数値的な保留を設計する。
5. 多項式では標準単項式係数と選んだ基底の座標を区別する。0Dの扱い、表示する証明／手順の範囲、追加Labか既存Labの拡張か、共有とResetの範囲は承認前に確定扱いにしない。

次の詳細設計には**「高」を推奨**する。対角化可能性の数学的条件、数値計算で確認できる範囲、基底変換の向きを横断して決めるため。設定変更は利用者が行う。
