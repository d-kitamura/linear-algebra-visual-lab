## 1. 表記と教材上の意味

- メニューは「固有値・固有空間Lab」、見出しは「固有値と固有空間」。同一空間の線形変換T: U→Uだけを扱う。
- 基準基底をmathcal E、同じ基準基底を入出力に用いた表現行列を太字斜体Aとする。入力は太字斜体u、多項式ならu=f(x)。標準単項式係数はb_0,b_1,b_2、固有値λはレギュラー斜体。
- 多項式の式は `[T(u)]_E=A[u]_E` と `[T(u)]_E=λ[u]_E`。多項式自体を生の係数列と等号で結ばない。数ベクトルの場合はAu=λuと書ける。
- `g(λ)=det(A−λE)`。gの根としての回数は「固有値の重複度」、独立な固有ベクトルの個数は「固有空間の次元 dim(W(λ;T))」と表示する。小さな補足で「固有方程式の根として何回重なるか」と説明し、幾何重複度という新しい表示語は増やさない。
- `W(λ;T)={u∈U | T(u)=λu}`。恒等変換をI_Uと書くと `W(λ;T)=Ker(T−λI_U)`。行列側では `Ker(A−λE)` に対応する。Eは行列、I_Uは写像として区別する。
- 固有空間は零を含み、固有ベクトルは零を除く。λ=0は零へ写る非零ベクトルを持つときの固有値である。0Dの零変換には非零ベクトルがないので固有値もなく、g(λ)=1。
- 固有空間の基底の一例にはq_1,...を太字斜体で用い、順序付き組Q=(q_1,...)のQのみカリグラフィ体で示す。多項式ではその係数列に対応する多項式も併記する。基底は一例であり唯一ではない。

## 2. 数学API（12.2実装済み）

### 入出力の共通規則

`EigenMapDefinition = { dimension: 0|1|2|3, matrix: readonly number[][] }`。行列は**行配列**、n×n、0Dは`[]`。入力は長さnの基準座標列を一次元配列で保持する。型の配列は実装時に内側もreadonlyとする。

成分は有限・絶対値100万以下。空間種別は数学APIへ渡さず、同じ係数計算を数ベクトルと多項式で使う。種別と次元の制約はLab状態・共有の検証で扱う。不正次元・行列形状・非有限・範囲外・入力次元不一致は`InvalidEigenInputError`で理由コードを返す例外とする。数値精度不足は例外ではなく解析結果にする。

APIは入力を変更せず、結果はreadonlyのスナップショット。内部計算に表示丸め・微小値の強制ゼロ化を使わない。既存`linearMap.ts`には表示用の`cleanNumber`があるため、その整理済みの像を固有判定へ流用しない。既存Labの動作を変えず、12.2で丸めない行列作用を使用する。

### analyzeEigenMap(definition): EigenMapAnalysis

入力uに依存しない解析。返すフィールドは以下とする。

| フィールド | 契約 |
|---|---|
| definition | 解析した次元・行列のスナップショット。他行列の結果を入力判定へ混ぜない |
| status | `ready` / `no-real-eigenvalues` / `inconclusive` / `numerical-failure` |
| characteristicCoefficients | gの**昇べき**係数[p_0,...,p_n]。長さn+1、最高次は(−1)^n。導出失敗ならnull。表示時だけ降べきに並べる |
| spectrumComplete | 実／非実の区別と実根の一覧・重複度まで数値基準内で確定しているか。固有空間の確かさとは別 |
| nonRealRootCount | 非実根の重複度込み個数。確定時0または2（n≤3）、未確定ならnull。内部の完全性検査用で、非実根自体は画面表示しない |
| realEigenvalues | 確認できた相異なる実固有値の昇順配列。1要素は下表。分離・実数性を確認できない候補は混ぜない |
| issues | 判定保留・失敗の理由配列。推定値は診断にとどめ、確認済みの固有値として学生へ提示しない |

実固有値1要素の契約:

| フィールド | 契約 |
|---|---|
| value | 有限の近似固有値。表示文字列ではなく計算値 |
| algebraicMultiplicity | 確認できた重複度1〜n、不確かならnull |
| eigenspace | 検証済みなら `{ dimension, basis, maxRelativeResidual }`、不確かならnull |
| issues | この根に対応する保留理由。基底不明を基底次元0と表さない |

`basis`は**列ベクトルの配列**であり行列の行配列ではない。長さdimension、各列の長さn、一次独立かつ全てAq≈λqを満たす。dimensionは1〜n、重複度が既知ならdimension≤重複度。部分的に見つかったベクトル1本だけで固有空間全体の基底だと認定しない。正規化・符号・順序は再現性のため12.2で固定するが、正しさは配列の文字列一致ではなく空間と残差で検証する。

結果の不変条件:

- `ready`: n>0、確認済みの実固有値が1つ以上、spectrumComplete=true、全根の重複度と固有空間が確認済み。非実根が残りの次元を占める場合も可。
- `no-real-eigenvalues`: spectrumComplete=true、実固有値配列は空、nonRealRootCount=n。0Dはn=0・係数[1]でこの状態。3Dの実行列に実固有値なしを返さない。
- `inconclusive`: 確認できた部分結果があっても全体または空間が不確か。spectrumComplete=trueでも固有空間を確認できないならこの状態。根配列が空でも「実固有値なし」と言わない。
- `numerical-failure`: 収束不能・非有限等により利用できる根を返せない。spectrumComplete=false、実固有値配列は空。計算できた固有多項式は保持可。
- spectrumComplete=trueのとき、実根の重複度合計＋nonRealRootCount=n。次数0を除き、定数項はdet(A)、λ^(n−1)の係数は(−1)^(n−1)tr(A)。残差だけで全根発見・重複度を保証した扱いにしない。
- 理由コードは`ambiguous-realness`、`unresolved-cluster`、`ambiguous-multiplicity`、`unstable-nullity`、`residual-too-large`、`incomplete-spectrum`、`iteration-limit`、`non-finite-result`を基本とする。12.2でprecision-limitとunrepresentable-resultを追加した。

### analyzeEigenInput(analysis, input, selectedEigenvalueIndex): EigenInputAnalysis

行列はanalysis.definitionから取得し、入力のドラッグごとに固有値分解をやり直さない。像は丸めず計算する。入力の形状不正は例外。像が非有限なら理由付きの計算失敗を返し、古い像で代用しない。

以下を別々に返し、1個の真偽値へ潰さない。

| 項目 | 状態 |
|---|---|
| 入力そのもの | `zero` / `nonzero`。**全成分が厳密に0**のときだけzero（−0も0）。小さい非零入力を零扱いしない。0Dの[]はzero |
| 選択空間との関係 | `no-selection` / `member` / `not-member` / `inconclusive` |
| 固有ベクトルか | `zero-input` / `eigenvector` / `not-eigenvector` / `inconclusive` |

検証済み空間への所属とAu≈λuの整合を確認し、基準内ならmember。境界・矛盾はinconclusive。選択λが存在しても空間が未確定ならmember判定を出さない。選択空間以外も調べ、確認済みの一致根の序数を返せるようにする。

非零入力がいずれかの検証済み空間に属すればeigenvector。`not-eigenvector`を返すのは全実根・全空間が確認済みで、全てに対して不所属を確認した場合だけ（実固有値なしはこれに含む）。どこかが不確かならinconclusive。零入力は常にzero-inputであり、所属はmemberでも固有ベクトルではない。

残差の指標は `||Au−λu||₂ / ((||A||F+|λ|)||u||₂)` とする。分母0・残差0なら0、分母0・残差非零は計算失敗。小さい入力に対して分母へ一律1を加えて誤判定しない。浮動小数の途中のunderflow/overflowを避ける評価方法と採用閾値は12.2で検証する。利用した残差・所属距離・理由を結果へ返し、保留をUIで説明できるようにする。

### 描画・吸着へ渡す境界

数学APIからReactやカメラを参照しない。Lab側の変換関数`createEigenSpaceGeometries`はeigenspaceが非nullの全要素を空間ごとに共通描画へ渡す。異なる固有直線を合わせて平面と解釈しない。不確かな全体の中に確認済み空間がある場合はその空間のみ表示可、ただし一覧が不完全であることは通知する。

吸着には正規化済みの全空間基底を使い、UI距離は2D表示幅2%・3D3%、原点最優先。空間表示をオフにしたらその空間への吸着もオフにし、見えない板へ吸着させない。原点吸着は表示設定に関係なく維持する。1Dは既存数直線の原点吸着を共用する。表示・吸着の数値は数学APIの許容誤差を変更しない。

## 3. Lab状態と全固有空間表示（D-106）

状態は4層に分ける。

1. 確定教材状態: `{ kind, dimension, matrix, input, showEigenspace }`。
2. 表示状態: 次元別の手動範囲、3Dカメラ、タブ。
3. 一時状態: 数値下書き、ドラッグプレビュー、入力エラー。確定状態と混ぜない。
4. 導出状態: 数学解析・像・表示できる空間・表示式・図。URLやReset基準へ保存しない。

7つの場面IDは`coordinate-0`〜`coordinate-3`、`polynomial-1`〜`polynomial-3`。既定の場面と数値は下表。基準行列は行配列で保持する。初期カメラは既存の3D既定値、解析タブは「固有値」、showEigenspace=false（D-106）。

| 場面 | A | 入力（基準座標） |
|---|---|---|
| coordinate-0 | [] | [] |
| coordinate-1 | [[−2]] | [1] |
| coordinate-2（起動時） | [[2,1],[0,3]] | [2,1] |
| coordinate-3 | diag(2,2,−1) | [1,1,1] |
| polynomial-1 | [[2]] | [1] |
| polynomial-2 | diag(0,1) | [1,1] |
| polynomial-3 | diag(0,1,2) | [1,1,1] |

種別切替で現在次元が有効ならその次元を保つ。coordinate-0から多項式への切替だけは直前の多項式次元（初回2）を選ぶ。次元・種別切替は保存済みの当該場面を選び、他の行列や入力をコピーしない。0Dは行列・入力・根選択の編集を置かない。

### 全空間表示と等号（D-106）

- 根のプルダウンと教材の選択状態を廃止。実固有値は昇順、重根は1要素のまま、すべての固有空間を個別に説明する。
- 初期状態・通常Resetは空間非表示。オンにすると確認済み空間をすべて描画し、同じ空間群への吸着を有効にする。表示オフでは原点への吸着だけ維持する。
- 吸着範囲が重なれば最短距離の空間を採用し、同距離なら実根昇順。原点を全候補より先に判定する。
- 2D初期行列の固有値は2・3、固有直線はx軸とy=x。入力[2,1]は維持し、固有値1による完全一致を最初の観察から避ける。
- 本Labの4解析カードは数値表示・所属等式を「=」に統一。内部精度・残差・判定保留・根の分離は変更しない。他Labの近似記号規則は維持する。
- 数学APIの単一空間を調べる任意引数selectedEigenvalueIndexは維持するが、Labでは指定せずmatchingEigenvalueIndicesを利用する。共有設計から選択フィールドを削除する。まだ未公開の第五Lab共有形式のため移行処理は作らない。

### Reset・プレビュー

初期Workspaceは起動時に一度構築し、共有URLは対象の1場面のみ置換する。Resetは現在の場面を初期Workspaceのその場面へ戻し、初期共有場面へ強制移動しない。他場面と直前の種別選択は維持する。表示範囲は全体表示、タブは「固有値」、3Dカメラはその場面の起動時カメラへ戻す。

入力ドラッグではプレビューから像と入力判定を更新し、終了時に一度確定、キャンセル時に開始前へ戻す。下書きエラー・ドラッグ中は共有を無効化する。有効入力で数学解析が保留なだけなら共有は可能。再エクスポートはReset基準を更新しない。

## 4. 共有v1の契約（12.7で実装）

通常場面のワイヤ形式例。JSONのmatrixは行配列、inputは基準座標。プロパティ名・出力順はこの例へ合わせる。

```json
{"v":1,"lab":"eigenspace","kind":"coordinate","dim":2,"matrix":[[2,1],[0,3]],"input":[2,1],"showEigenspace":false,"camera":null}
```

0Dの形式は次だけとする（kindはcoordinateへ復元）。

```json
{"v":1,"lab":"eigenspace","dim":0}
```

通常は全フィールド必須、未知フィールド・未知版・未知kind・不正形状・非有限・範囲外は拒否。polynomialはdim=1,2,3のみ。0D形式へ余分なkind/matrix/input等があれば拒否し、正規化で黙って捨てない。数学API内部の0D[]とワイヤ形式での省略を区別する。

cameraは1D/2Dでnull、3Dでは既存SharedCameraState（direction,target,up,zoom）必須。既存の有限値・方向と上方向の独立性・target上限・zoom範囲を共用する。共有直前に既定カメラが必要なら初期値で具体化する。

根・空間基底・係数多項式・像・解析結果・数値許容値・表示桁数・手動範囲・タブ・全7場面は含めない。基準基底はkind/dimから再構成し、余分な基底配列は保存しない。3Dカメラと数学上の入力状態は別に保持する。

実装時は独立fixture、文字列が決定的な再生成、2048文字上限、QR・PNG・コピー・テキスト、未知版、不正値、解析保留の共有、空間表示設定と共有時Resetを検証する。既存4Labへ影響する変更は行わず、アプリ内のLab追加とデコーダー接続は12.3／12.7で行う。

## 5. 12.2へ渡す独立した期待値と未決定事項

固有多項式の係数方向・奇数次符号を以下で固定する。

| A | gの昇べき係数 | 実固有値: 重複度／空間次元 |
|---|---|---|
| 0D [] | [1] | なし |
| [−2] | [−2,−1] | −2: 1／1 |
| [[2,1],[1,2]] | [3,−4,1] | 1: 1／1、3: 1／1 |
| [[0,−1],[1,0]] | [1,0,1] | なし（非実根数2） |
| [[2,1],[0,2]] | [4,−4,1] | 2: 2／1 |
| diag(2,2,−1) | [−4,0,3,−1] | −1: 1／1、2: 2／2 |
| 3D零行列 | [0,0,0,−1] | 0: 3／3 |
| 3D多項式微分 | [0,0,0,−1] | 0: 3／1 |
| 3D多項式平行移動 | [1,−3,3,−1] | 1: 3／1 |

設計検算テストは係数表とdet(A−λE)の標本点の一致を独立に確認するものであり、固有値ソルバーを先行実装しない。

以下は12.1から引き継いだ検証事項（12.2の採用結果は数値解法記録を参照）: 非対称2D/3Dの全根探索・実数性・重複度の検証手法、近似λからの固有空間抽出、残差・根の分離・所属の許容値、安定な基底正規化、収束上限、依存導入の要否。共通rankのD-009やUI吸着距離を数値精度の代わりに変更しない。

新規依存または契約を満たす範囲の変更が必要なら採用前に相談する。D-104は承認済み。12.3の画面はD-105の確認を経て12.4へ進む（推奨「高」）。
